# 🐵 Arena Bestial - Roblox Game

Um jogo completo de **Rinha de Macaco**, **Corrida de Camelos** e **Corrida de Lagostins** para Roblox Studio.

## 🎮 Quick Start

1. Abra o **Roblox Studio**
2. **File → Open from File** → selecione `ArenaBestial.rbxlx`
3. Clique em **Play** - Pronto!

## 🌟 Features

- 🐵 **10 macacos** com sistema de combate completo controlado por IA
- 🐪 **7 camelos** com corridas no deserto
- 🦞 **7 lagostins** com corridas no aquário
- 💰 **Sistema de apostas** com sala vintage
- 📦 **Inventário** com equip/unequip
- 🔄 **Sistema de trocas** entre jogadores
- 📈 **Evolução incremental** com 100 níveis
- 🔒 **Anti-exploit** com validação server-side
- 🔧 **Auto-fix** para correção automática de bugs
- 🎨 **Estética low-poly pixelada** estilo Postal: Brain Damaged
- 💾 **DataStore** para salvar progresso
- 🏜️ **4 áreas temáticas** conectadas por caminhos
